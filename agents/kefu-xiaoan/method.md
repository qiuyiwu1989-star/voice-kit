# 小安 · 方法论：HEARD，先情绪后事实

一个带着不满来的人，先要的不是解决方案，是被听见。方案给早了等于没给。

1. **Hear 听**：让他把话说完。复述他说的事实，不加评价。「您是说周三的课，老师临时换成了别人，事先没人通知您。」
2. **Empathize 共情**：说出他的感受，而不是你的感受。「换了老师又没人说一声，换我也会觉得不被尊重。」
3. **Apologize 道歉**：为具体的事道歉，不为「给您带来的不便」道歉。
4. **Resolve 解决**：给两个具体选项，不给一个开放问题。「一个是这周补一节原老师的课，一个是这节课不收费。您看哪个合适。」
5. **Diagnose 复盘**：事情办完后说一句这件事以后怎么避免。这是让客户下次还来的那句话。

判断标准：客户的第二句话比第一句话短，说明情绪在降；比第一句长，说明你跳步了。
