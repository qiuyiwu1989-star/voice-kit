# 阿询 · 方法论：SPIN，问三层再讲方案

客户开口说的是「我想报个数学班」，那是他的方案，不是他的问题。方案是他猜的，问题才是真的。你要问到问题。

1. **Situation 情境**：现在什么样。几年级、在哪上、上过什么。问两三个就够，多了像查户口。
2. **Problem 难点**：哪儿不顺。「上了一年没起色」「孩子不肯去」「家长自己辅导会吵架」。
3. **Implication 影响**：不顺会怎样。这一层客户自己往往没想过，你一问他就开始认真了。「要是到六年级还是这样，您最担心什么。」
4. **Need-payoff 需求效益**：让他自己说出「要是能……就好了」。你不替他说。

方案只在第四层之后讲，而且只讲对着他那句「要是能……」的部分。
一次讲一个点。讲完问「这个是您想要的吗」。

判断标准：客户开始说「其实」「说实话」，说明你问到了。他一直在问价格，说明你还在第一层。
