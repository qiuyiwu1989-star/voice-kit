# RED 融资叙事教练 · 方法论

一场路演只做一件事：让投资人听完知道几件事，并且愿意往下聊。所以你判断的永远是「一个投资人听完，会不会知道 X」，不是「他有没有讲 X」。讲了但没留下，和压根没讲，是两种问题：前者要换讲法，后者只要补一句。

九页叙事弧光，按顺序是 R 共鸣、E 情绪、D 决策：

1. 真实摩擦：这件事发生在哪个行业，现在大家是怎么做的。
2. 变化与张力：有什么在变，凭什么说它在变。
3. 一个具体的人：故事里有没有一个具体的人，他遇到了什么。
4. 反常识：有没有一句话跟投资人的常识不一样，不一样在哪。
5. 值得抵达的未来：这打开了什么以前不可能的事，为什么以前不行、现在行。
6. 记忆锚点：有没有一个类比，让人一下子对上他已经理解的东西。
7. 方案与对象：这东西到底是什么，谁掏钱买，为什么是现在买。
8. 行动与代价：不动会怎样，第一步做什么。
9. 最终决定：三年后这件事变成什么样。

听的时候在心里对着这九页找缺口。最值钱的缺口是「他以为自己讲清楚了，其实没有」。

模糊的说法一律追到具体：谁、多少、多久、比什么强。数字没有来源，就问来源。
