# 后台登录（账号密码）

2026-09-17 起，人进 voice-kit 统一后台（`/admin/agents` `/admin/memory` `/admin/feedback`）走
`/admin/login` 的**用户名 + 密码**。原来的「管理员门票」`VOICEKIT_ADMIN_TOKEN` 保留，只给脚本和自动化用，
页面上不再提它。代码：`voice_kit/admin_auth.py`、`voice_kit/admin_password.py`；测试：`tests/test_admin_login.py`。

## 服务器上存什么

只存哈希，**明文密码不进服务器 env、不进仓库、不进提交信息**。都写在 `/etc/voicekit-svc.env`：

| 变量 | 说明 |
|---|---|
| `VOICEKIT_ADMIN_USER` | 用户名。不配就是 `qiuyiwu` |
| `VOICEKIT_ADMIN_PASSWORD_HASH` | 密码哈希（scrypt，带盐）。**不配 = 账号密码登录不可用**，后台维持老行为（只认门票），绝不放行 |
| `VOICEKIT_ADMIN_SESSION_SECRET` | 可选。会话签名密钥；不配时从密码哈希派生 |
| `VOICEKIT_ADMIN_TOKEN` | 可选。脚本门票（`Authorization: Bearer …` / `?k=`） |

门票和密码哈希都没配时，整个后台（含登录页）404。

## 设置 / 更换密码

在服务器上（交互式输两次，不回显，不进 shell 历史）：

```sh
cd /opt/voicekit-svc
venv/bin/python -m voice_kit.admin_password
# → VOICEKIT_ADMIN_PASSWORD_HASH=scrypt:16384:8:1:...:...
```

把输出那一行写进 `/etc/voicekit-svc.env`（已有同名行就替换），然后：

```sh
sudo systemctl restart voicekit-svc
```

运维管道用 `--stdin`（从标准输入读第一行）：

```sh
read -rs PW && printf '%s\n' "$PW" | venv/bin/python -m voice_kit.admin_password --stdin; unset PW
```

哈希里的分隔符是冒号、base64 是 urlsafe 无填充，**不含 `$`**，写进 systemd EnvironmentFile、`.env`、
docker-compose 都不会被当成变量展开。

**换密码 = 所有旧会话立刻失效**（会话签名里揉了哈希指纹，单独配了 `SESSION_SECRET` 也一样）。
想「踢掉所有人但不换密码」：改 `VOICEKIT_ADMIN_SESSION_SECRET` 再 restart。

> **强烈建议上线后马上换成强密码**（12 位以上、字母数字符号混合）。
> 默认约定的那个初始密码是纯数字、很短，只适合第一次进去；防爆破规则能拖慢在线猜测，
> 但挡不住「密码本身太好猜」。生成哈希时命令行会对弱密码打一行提醒。

## 登录流程

1. 未登录打开后台页 → 302 到 `/admin/login?next=<原地址>`；未登录调后台接口 → 401 JSON。
   页面里的接口调用拿到 401（会话过期、换了密码）→ 自动跳登录页，登录完回原页。
2. 登录页：用户名、密码、「登录」。错了只说「用户名或密码不对」，不区分哪个错；
   用户名错时也照样算一遍哈希，响应时间不泄露差别。
3. 成功 → 发 cookie `vk_admin_session`：HttpOnly、SameSite=Lax、7 天；
   请求是 https 或带 `X-Forwarded-Proto: https`（nginx 已配）时加 Secure。
4. `next` 只放行站内 `/admin/...` 路径；外站、`//host`、反斜杠、控制字符一律回 `/admin/agents`。
5. 左侧导航底部「退出登录」→ `/admin/logout` 清 cookie（连同老的门票 cookie）回登录页。
   顶栏显示当前用户名。

## 防爆破

- 同一 IP 连续失败 **5 次锁 15 分钟**；锁定期间不校验密码，直接回「用户名或密码不对，稍后再试」（HTTP 429）。
  登录成功清零。
- 全站**每分钟失败超过 30 次**：所有人的账号密码登录临时拒绝，直到窗口里的失败数降下来。

局限（写清楚）：

- 计数在**进程内存**里：restart 清零；多 worker / 多机各算各的（现在是单进程 uvicorn）。
- IP 取 `X-Real-IP`（nginx 用 `$remote_addr` 覆盖写入，客户端伪造不了）。服务如果绕过 nginx
  直接暴露，这个头就能伪造，只剩全局限速兜底——服务只监听 127.0.0.1，保持这样。
- 全局限速意味着有人持续乱试时，真管理员也会暂时登不进；这时可以用门票进。

## 审计

每次登录尝试追加一行到 agents 目录（`VOICEKIT_AGENTS_DIR`）下的 `_admin_audit.jsonl`：

```json
{"at": "2026-09-17T10:42:00", "ip": "1.2.3.4", "user": "qiuyiwu", "result": "ok"}
```

`result`：`ok` / `fail` / `locked`（该 IP 在锁）/ `global`（全站限速）。不记密码。
`_` 开头，`agents.load_all` 只认目录且跳过 `_`，不会被当成 agent；已加进 `.gitignore`。
