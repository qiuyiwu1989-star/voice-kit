## 4. 步骤
### 阶段 A：准备（交付结束后，不停服务）
1. [voice-kit] 上海装 pm2、ffmpeg；建 Postgres 角色 `rep` 与库 `rep`（密码只在服务器 env）。
2. [voice-kit] 拷证书；上海 nginx 加 jiaolian / voice 两个站点（先不生效，DNS 还在南京）。
3. [AI 教练] 上海 `/home/ubuntu/apps/rep/.env` 按南京复制，改 `DATABASE_URL` 指向上海库，`VOICEKIT_BASE_URL=http://127.0.0.1:8020`；`REP_HOST=ubuntu@150.158.186.157` 跑 deploy.sh。
4. [用户] 两个域名 TTL 调 60 秒。

### 阶段 B：彩排（临时域名，不影响线上）
5. [用户] 加一条临时解析 `jiaolian-sh.qiuyiwu.com → 150.158.186.157`（voice-kit 已有 duihua.qiuyiwu.com）。
6. [voice-kit] 用南京库的**当前快照** pg_dump → 上海 `rep` 库；记忆文件 rsync 到上海 voice-kit。
7. [AI 教练] 在上海跑全部 try:* 回归；真机在临时域名通一场中文视频、一场英文视频、一场文字、结束看复盘。
8. [两边] 记下从停写到验证完的实际耗时，作为正式窗口的依据。彩排数据在正式窗口前清空重导。

### 阶段 C：正式窗口（约 23:00，停写 15–30 分钟）
9. [voice-kit] 南京：nginx 对 jiaolian / voice 返回维护页（503 + 一句话），`pm2 stop rep rep-retain rep-nextup`，注释掉 ubuntu crontab 里的 realtime-sweep，`systemctl stop voicekit-svc`。
10. [voice-kit] 最终数据：`pg_dump rep` → 上海 `pg_restore`；`/var/lib/rep/audio` rsync（保持属主权限）；voice-kit `agents/users`、`agents/_feedback`、`tenants.json` rsync 到上海。
11. [voice-kit] 核对：两边逐表 `count(*)` 一致；记忆文件数、回流行数一致；输出对账表。
12. [voice-kit] 上海启动 voicekit-svc；[AI 教练] 上海 `.env` 的 PUBLIC_ORIGIN 改回 jiaolian、`pm2 start rep rep-retain rep-nextup`、加上 realtime-sweep crontab；本机 curl 两个站点（Host 头）通过。
13. [用户] 改两条 A 记录到 150.158.186.157。
14. [两边] 外网验证：Agent 中心、一场视频通话（含回调）、复盘、后台、记忆写入；上海跑 try:*。
15. [voice-kit] 上海 `certbot renew --dry-run`；上海备份 cron 覆盖 REP 库；南京保持停写只读 **7 天**作回退，之后下线南京上的 REP 与 voice-kit（其他项目不动）。

## 5. 回退
- 窗口内任一步失败：把 A 记录改回南京 → 南京 `pm2 start rep`、`systemctl start voicekit-svc`、撤维护页。南京数据停写后未动，可直接恢复。
- 切换后 7 天内发现问题：上海新数据先 pg_dump 保存，再按上面回退；新产生的数据人工合并（量小）。

## 7. AI 教练总指挥核对后补充（2026-09-17）
1. **pm2 是三个进程**：`rep`、`rep-retain`、`rep-nextup`（web-push 推送，VAPID 钥匙在 .env）。窗口里三个一起停、上海三个一起起；只起一边会导致推送重复或漏发。
2. **ubuntu crontab 有一条 REP 任务**：每 10 分钟 `scripts/realtime-sweep.ts --stop`，兜底停掉没收尾的 TRTC 任务和录制。切换后**删南京这条、上海加上**；两边同时跑会拿各自的库去停对方的房间。
3. **/var/lib/rep/audio 有约 2.6M 早期本地音频**（现在 STORAGE_PROVIDER=s3，但老场次还在本地盘）。窗口里一起 rsync，目录和权限保持一致。
4. **彩排时上海 `.env` 的 `PUBLIC_ORIGIN=https://jiaolian-sh.qiuyiwu.com`**。TRTC 模型回调用它拼地址；写成线上域名，上海发起的通话会回调到南京生产库。正式切换前改回 jiaolian。上海 .env 由 AI 教练总指挥写。
5. **彩排组合**：上海 REP → 上海 voice-kit 测试环境（127.0.0.1:8020），记忆写进测试环境，正是要验的组合。
